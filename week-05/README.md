# 5주차 · 개발 진행 보고 (하드웨어)

UOS 공식 템플릿을 사용한 11장·10분 10초의 하드웨어 진행 보고이다. 차체 실측, 포크·동봉 팔레트 실측(작성 중),
조종기·제어기 리버스 엔지니어링(측정 구성 · 명령별 파형 · 파형 해석 · 결론), 하드웨어 선정(DRV8244-Q1 SPI형 · MT6701),
표준 운용 절차 대조, 리보틱스 중간 미팅 질문으로 구성한다. 구성의 근거는 [PLAN.md](PLAN.md).

2026-09-29 에 만든 2D LiDAR 시뮬레이션 장(스캔 · 지도 작성 · 지도 비교 · 위치 추정 오차)과 영상·데이터·생성 스크립트는
사용자 결정에 따라 6주차로 미뤄 [`../week-06/`](../week-06/) 초안에 보관했다.

- [build_deck.py](build_deck.py): 본문·원고·시간 배분의 편집 원본.
- [prepare_la.py](prepare_la.py): DSLogic CSV 3개에서 엣지만 뽑아 `assets/data_la_edges.json` 을 만든다(표준 라이브러리만).
- [SCRIPT.md](SCRIPT.md): 장별 한국어 발표 원고와 출처.
- [SOURCES.md](SOURCES.md): 수치와 화면의 출처.
- [VALIDATION.md](VALIDATION.md): 이 자료의 검증 기록.
- [PLAN.md](PLAN.md): 구성 계획과 교차검증 기록.
- `index.html`, `SCRIPT.md`, `slide-metadata.json`: 생성 파일. 직접 수정하지 않는다.

## 남은 작업

- 2–3쪽: 차체·포크·팔레트 실측값과 사진으로 자리 표시를 교체한다.
- 5쪽: 조향 CSV 는 캡처 15.95 s 중 7.72–16.69 s 만 들어 있어 왼쪽 명령 1회만 보인다. 전 구간을 다시 내보내면 `prepare_la.py` 로 갱신한다.
- 8–9쪽: DRV8244·MT6701 의 실제 쓰임(어느 모터·축, 개수)이 정해지면 반영한다.

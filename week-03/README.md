# 3주차 · 개발 진행 보고

UOS 공식 템플릿을 사용한 14장·11분 50초의 진행 보고이다. 팔레트 포켓 인식의 구현과 평가, 실물 규격 형상으로의 일반화, 그리고 측정에서 드러난 2D LiDAR·카메라 장착 조건으로 구성한다.

2주차가 개발 계획(안)이었던 것과 달리 이 자료는 **측정 결과 보고**다. 모든 수치는 합성 장면에서 잰 값이며 실물 성능이 아니다.

- [build_deck.py](build_deck.py): 본문·원고·시간 배분의 편집 원본.
- [SCRIPT.md](SCRIPT.md): 장별 한국어 발표 원고와 출처.
- [SOURCES.md](SOURCES.md): 수치와 화면의 출처, 그리고 각 화면을 만든 렌더러.
- [VALIDATION.md](VALIDATION.md): 이 자료의 검증 기록.
- `index.html`, `SCRIPT.md`, `slide-metadata.json`: 생성 파일. 직접 수정하지 않는다.
- `assets/`: 로봇 저장소에서 생성한 그림과 영상. 손으로 그린 값은 없다.

이 폴더에서 `python3 build_deck.py`로 3주차만 재생성할 수 있다. 레포 루트의 `python3 build_deck.py`는 모든 주차와 목록을 재생성한다.

레포 루트에서 `bash present.sh`를 실행한 후 `http://127.0.0.1:8765/week-03/`를 연다. `F`는 전체화면, 방향키는 슬라이드 이동이다. 5·9·12쪽의 영상은 자동 반복하며 재생 제어 버튼은 없다.

**화면마다 렌더러가 다르다.** Gazebo Harmonic 촬영, MuJoCo 차체 모델 렌더, 그리고 임의 자세를 계산하는 측정 리그 세 가지가 섞여 있고 각 캡션에 표기했다. 측정 리그는 시뮬레이터가 아니라 상자 광선교차로 깊이만 계산하는 도구다.

**SLAM 지도는 이 자료에 없다.** 2D LiDAR 관측과 기록·재생까지가 확보된 범위이고, 지도 작성과 위치 추정은 차체 입고 후의 단계다.

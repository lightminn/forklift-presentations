# 3주차 자료 출처

모든 수치는 로봇 저장소(`forklift/`)의 검증 기록과 계획 문서에서 가져왔고, 모든 그림은 그 저장소의 커밋된 코드·설정으로 생성했다. 손으로 그리거나 추정한 값은 없다.

## 화면을 만든 렌더러

| 렌더러 | 쓰인 곳 | 성격 |
|---|---|---|
| **Gazebo Harmonic** | 4·7·8쪽 화면 | 실제 시뮬레이터 렌더. 조명·재질이 있다 |
| **MuJoCo** | 5쪽 외부 시점, 7·11·12쪽 | 잠정 차체 모델(`dls08_provisional`)과 팔레트 모델 |
| **MuJoCo 광선 투사** | 3쪽 LiDAR 평면 | `mj_ray` 720빔·8 m |

| 도식 | 2·5·8·11쪽 | 저장소 수치에서 직접 그린 그림 |

## 구분해서 읽을 것

- **합성 결과이지 실물 성능이 아니다.** 실센서 깊이 오차는 2.5 m 에서 약 50 mm 로, 이 자료의 어떤 잡음보다 크다.
- **제작 예정인 축소 T11 의 촬영·평가는 아직 없다.** 8쪽 수치는 표준 규격(EPAL 6) 형상이다.
- **카메라 장착은 확정되지 않았다.** 9쪽은 측정 결과와 현재 기준선이며 최종값은 차체 실측 후 정한다.
- **거리 표기는 카메라에서 팔레트 전면까지다.** 저장소 측정 기록의 장면 배치 좌표와 1.05 m 차이가 난다.

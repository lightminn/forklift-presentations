# 3주차 자료 검증 기록

확인일: 2026-09-15.

## 확인한 것

- `python3 build_deck.py`로 14장·710초(11분 50초) 생성. 장수와 시간 합계는 빌드에서 단언으로 고정했다.
- 모든 그림과 영상을 로봇 저장소의 커밋된 코드·설정으로 생성했고 `assets/`에 함께 둔다.
- 1920 × 1080 헤드리스 렌더로 3·5·9·12·13쪽의 배치를 확인했다. 영상 3개는 자동 재생·반복한다.
- 각 화면 캡션에 그것을 만든 렌더러를 적었다. Gazebo·MuJoCo·측정 리그가 섞여 있다.
- 수치는 전부 [SOURCES.md](SOURCES.md)의 검증 기록에 대응한다.

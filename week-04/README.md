# 4주차 · 개발 진행 보고

UOS 공식 템플릿을 사용한 11장·10분 10초의 진행 보고이다. 차체 입고와 조작 축(실물 사진 두 장),
3주차 피드백에 답하는 카메라 장착 조건 세 장, 카메라 모형 교정·임무 입력 구성·운반 임무,
그리고 향후 계획으로 구성한다.

3주차와 달리 이 자료에는 **실물 사진이 들어간다.** 다만 실물에서 잰 수치는 하나도 없다.
보고한 수치는 전부 컴퓨터로 만든 장면에서 측정한 값이다.

- [build_deck.py](build_deck.py): 본문·원고·시간 배분의 편집 원본.
- [SCRIPT.md](SCRIPT.md): 장별 한국어 발표 원고와 출처.
- [SOURCES.md](SOURCES.md): 수치와 화면의 출처, 그리고 각 화면을 만든 것.
- [VALIDATION.md](VALIDATION.md): 이 자료의 검증 기록.
- `index.html`, `SCRIPT.md`, `slide-metadata.json`: 생성 파일. 직접 수정하지 않는다.
- `assets/`: 실물 사진과 로봇 저장소에서 생성한 그림·영상. 손으로 그린 값은 없다.

이 폴더에서 `python3 build_deck.py`로 4주차만 재생성할 수 있다. 레포 루트의 `python3 build_deck.py`는
모든 주차와 목록을 재생성한다.

레포 루트에서 `bash present.sh`를 실행한 후 `http://127.0.0.1:8765/week-04/`를 연다. `F`는 전체화면,
방향키는 슬라이드 이동이다. 10쪽의 영상은 자동 반복하며 재생 제어 버튼은 없다.

**화면마다 만든 것이 다르다.** 실물 사진(2026-09-23 촬영), Isaac Sim 렌더, 그리고 측정값에서 그린
도식 세 가지가 섞여 있고 각 쪽의 발표자 노트에 표기하였다.

**사진은 공개용으로 처리한 사본이다.** 원본 11장 중 9장에 위도·경도 EXIF 태그가 있어 전부 제거하였고,
다른 팀의 장비가 찍힌 배경은 잘라냈다. 원본은 저장소 밖에 두고 체크섬으로 연결한다 —
로봇 저장소의 `docs/validation/2026-09-23-chassis-intake.md` §5 참조.

수치는 컴퓨터로 만든 장면에서 측정한 값이며, 차체는 아직 실측하지 않았다.
